# CarePlus Hospital Management System

SDC Project Review-1 project using only HTML, CSS and JavaScript.

## Modules
- Patient Module
- Doctor Module

## Features
- Patient login
- Doctor login
- Separate dashboards
- Patient records
- Appointment booking
- Prescription management
- Billing
- Local Storage
- JavaScript navigation
- CSS Grid and Flexbox
- Responsive hospital-style UI

## Run
Open index.html in a browser or use VS Code Live Server.

No backend or database is used.


## Patient Create Account
Patients can click "Create New Patient Account", enter their name, email, password and age, and create an account. The details are saved in Local Storage. After registration, the email and password are filled into the login form so the patient can directly login.

## Patient Dashboard
A registered patient sees their own name, age, email, patient ID, appointments, prescriptions and bills. Doctor accounts see the doctor dashboard and patient management features.
